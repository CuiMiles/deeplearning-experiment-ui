# MotionBench半小时帧率诊断

完成 16/128 次推理，冻结 8 个视频、每个视频1道官方DEV题。

两代原始模型均不训练。2FPS候选帧是8FPS候选帧的子集；每个帧率下三种方法使用相同画面。空间token网格在模型间匹配，实际像素尺寸不同。
主对照使用公开免训练代码的PI卷积调整规则；另列固定6帧的重复初始化敏感性对照。固定6帧最后不足6帧时重复尾帧，数量逐条记录。2/8FPS表示抽帧密度，固定2/6帧表示共同编码的组长。
注意：这是小规模免训练机制核验，不能复现经过训练的正文表2，也不能估计整个MotionBench的准确率。
