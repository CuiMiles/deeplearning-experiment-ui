# 多区间短事件 CPU 诊断

93K 文件中 12233 条多区间 query；合并相邻 GT/预测支持后，用 IoU≥0.5 一对一匹配。
最短/最长 GT 时长不同的候选中，最短段召回 22.62%；最长段召回 38.91%。
集合 IoU≥0.8、但漏独立区间的候选 6850/12139；涉及 2258 条 query。
其中高集合 IoU 且至少一段 GT 与预测完全零重叠：2451 个候选。
原奖励最佳候选的实例 F1 严格低于该组最大 F1：3239/12233 组。
训练时长范围内：最短召回 23.41%，最长召回 39.98%。

这是官方 SFT rollout 的训练分布诊断。合并支持不能确认语义上每次独立发生；并未评估已发布 GRPO 模型。
缺少实际帧索引，无法判断短事件是否被采到，不能把结果直接归因于奖励。未增加任何 GPU 作业。
