# 多次动作被报成一个长区间

若一个预测框完整包含两个相邻、有正间隔的标注动作，该题记一次吞并。同题可以同时有吞并和向外误报。
“拆开并多命中”要求原来被吞的一对动作分别与两个输出框有重叠，这一对和全题的一对一正确匹配数都增加。另一对动作仍可能被吞。
