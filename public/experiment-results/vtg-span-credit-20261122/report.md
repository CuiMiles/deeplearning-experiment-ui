# 两个时间段里只有一个补对了，该奖励哪一个

上轮 64 条正例含 127 个预测时间段。按 IoU≥0.5 一对一匹配，66 段补中了前四次回答漏掉的事件，25 段属于前四次已报对的事件，36 段没有匹配成功。

例如，模型寻找漫画风格海报，回答了 10–50 秒和 72–111 秒。标注为 66–111 秒和 113–126 秒。后一个预测补中了第一段海报画面，前一个预测与任何标注都没有重叠。上轮整句正向模仿同时奖励了这两段。

新实验已固定 235 条回放答案，来自训练集的 156 个视频。两组使用相同的视频、完整回答、普通 A1 强化学习和回放损失系数。一组对全部时间数字计算回放损失；另一组只对新匹配成功的时间段中的数字计算回放损失。每条回放先取所选数字的平均损失，答案各使用一次。额外回放全程使用普通提示，模型看不到次数或标准时间。

正式评测包含 784 个视频、1,071 道题，比较多事件定位分数、精确率和召回率，附原 A1 对照及单事件结果。训练和评测均已排入同一后台服务，完成后本页自动更新。
